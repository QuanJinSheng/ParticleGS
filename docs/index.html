ParticleGS learns continuous Gaussian particle dynamics from multi-view videos to extrapolate future 3D motion.

Abstract

Dynamic 3D reconstruction methods can render observed motion with high visual quality, yet extending that motion beyond the available video remains challenging. ParticleGS addresses this problem by representing a dynamic scene as a system of Gaussian particles with learned latent dynamics. An encoder separates each particle’s static features from a compact set of shared dynamic fields. A Neural ODE evolves these fields continuously in time, and a decoder converts the resulting states into Gaussian translations, rotations, and scale changes for rendering. The model is optimized directly from multi-view videos without prescribing governing physical equations or requiring simulation supervision. This state-based formulation supports future motion prediction and novel-view synthesis while keeping the evolving representation compact. Experiments on three synthetic benchmarks and the real-world FreeGave-GoPro dataset show improved extrapolation PSNR over the evaluated baselines, alongside competitive rendering speed.

From Observed Motion to Future Prediction

Method Overview

Dynamics Latent Space Encoder. Neighborhood aggregation and attention map Gaussian features to particle-specific static features and a compact set of shared initial dynamic fields.

Neural ODE Dynamics Evolver. A learned continuous-time transition function evolves the shared dynamic fields with an RK4 solver, supporting prediction beyond the observed temporal range.

Gaussian Kernel Space Decoder. The evolved states are converted into Gaussian translations, rotations, and scale changes, then rendered at a requested time and viewpoint.

Future Motion Extrapolation

Given the observed portion of a multi-view sequence, ParticleGS evolves its learned latent state to render later moments from new viewpoints. Evaluation uses the final 25% of frames after training on the first 75%.
