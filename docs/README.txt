ParticleGS Project Website

Open index.html in a modern browser, or serve this folder with a static web server.
All paper, video, and figure assets are included. Keep the assets folder beside index.html.

GitHub Pages: existing ParticleGS code repository
1. Upload the docs folder from ParticleGS-GitHub-Pages.zip to the root of your repository.
2. Ensure docs/index.html, docs/styles.css, docs/app.js, docs/assets/, and docs/.nojekyll are present.
3. In Settings > Pages > Build and deployment, choose Deploy from a branch.
4. Choose the main branch and /docs folder, then Save.
5. After deployment completes, visit https://YOUR-USERNAME.github.io/ParticleGS/.

For a new dedicated website repository, upload the contents of docs to the repository root,
then choose main and /(root) in Pages settings.

The website uses relative asset paths and needs no build step.
Source code: https://github.com/QuanJinSheng/ParticleGS
